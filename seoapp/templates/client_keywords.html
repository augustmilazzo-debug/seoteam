How this works

The system proposes keywords from the client's services and locations. Tracked keywords get rank checks (Google + Maps) and drive page recommendations. Set the priority (1-5 stars) for how much you want each one: higher priority keywords get worked on first. Target page is the one page that should rank for that keyword (blank = a new page is recommended).
